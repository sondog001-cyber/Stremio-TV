## Proposed release text

Stremio TV provides a curated 111-identity US/Philadelphia lineup with direct
upstream playback, exact identity checks, normalized logos and native Live TV EPG.

This release adds scheduled-run evidence auditing, scoped local verification,
truthful decoder diagnostics, per-channel readiness reports and documented fork
setup. Existing installations retain addon ID `com.stremiotv.philly`, channel ID
prefixes, catalog IDs and the installation manifest URL.

Install the author's deployment:
`https://sondog001-cyber.github.io/Stremio-TV/manifest.json`.
For a fork, install your own Pages manifest as described in
[fork-setup.md](fork-setup.md). Upstream availability varies by network and time;
local exceptions remain separately labeled and do not certify normal CI success.

Before publication, replace this blocked draft with verified evidence for:

- Final original-channel count, normal QA count, local overrides and missing IDs.
- Three consecutive qualifying scheduled run URLs, final commits and artifact IDs.
- Critical History, Disney and National Geographic programme identity review.
- New/replaced-source burn-in, stability, backup promotion and no-repeat evidence.
- Zero generic logos, exact EPG mapping and actual Stremio playback confirmation.
- Successful final Pages deployment and final version/floor compatibility checks.

The v1.0.0 target remains all 111 original curated channels with the same quality
requirements, plus improved genuine independent backup coverage. No added or
substituted identities count toward either milestone.

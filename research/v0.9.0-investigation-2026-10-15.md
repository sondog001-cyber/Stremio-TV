## Implemented independent work

`release_readiness.py` audits actual GitHub scheduled production attempts and their
unexpired diagnostics artifacts, including intervening failures, rather than
counting carried site history. Its three-attempt window rejects manual/PR builds,
retries, wrong branches/workflows, stale/foreign artifacts, duplicate/unrelated
identities and weakened QA. It counts only normal upstream health plus real
Primary frame evidence, excluding local playback overrides. It preserves affiliate
suffixes and rejects West variants when counting the frozen original lineup.

The separate read-only workflow runs after production completion, never joins
Pages concurrency, never changes source selection, and cannot publish or tag.
Its output distinguishes an automated schedule gate from final release approval.
API bearer credentials are stripped before following signed artifact redirects.
The default branch's trusted code is used for workflow-run events.

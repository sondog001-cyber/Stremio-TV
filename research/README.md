# Historical stream-stability keys

The `stability_key` fields in `v0.9.0-intermittent-evidence-2026-10-15.json` are deterministic 40-character SHA-1 digests generated by `_stream_stability_key` in `build_parts/part04.txt` from stream URLs and headers. They are **identifiers, not authentication credentials**. Twenty exact Gitleaks fingerprints for these values are documented in `.gitleaksignore`; do not expand those exceptions to other files or arbitrary hashes.
